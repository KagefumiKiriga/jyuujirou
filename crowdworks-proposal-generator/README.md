# CrowdWorks提案文ジェネレーター

## テーマ選定理由
製造業(Canon)での現場経験を活かし、フリーランス活動を支える
「CrowdWorks提案文ジェネレーター」を開発。
現場を知るエンジニアとして、今後は他の現場課題にもAIで
アプローチしていきたいと考えている。

## 使ったDify機能
1. チャットボット作成(LLMノード:gpt-4o-mini)

## 構成
ユーザー入力 → LLM(System Prompt) → 回答

## System Promptのポイント
- 提案文の5段階構成(挨拶→自己紹介→提案→納期→締め)
- 文字数300〜400字指定
- 勝太さんのスキル(GAS/LINE/Dify/Stripe/Python)を反映
- 100点満点のスコア＋改善点を1つ添える設計

## テスト結果
95点で合格ライン突破
